Recipe Saver, how it works

A recipe book that lives on your computer: a page in your browser, a small server program, and one file. Nothing goes online.

The big picture

Three parts, one loop. The page in your browser is the table: a form, a list, a search box. Behind it, a small program called the server (the program that listens for requests and answers them) is the kitchen: it checks every recipe you save and keeps the book. The book itself is one file, recipes.json. Once you can read this picture, every other one below is a zoom-in.

What happens when you save

You fill in the name, maybe the ingredients and steps, and click Save. Five things happen in about a blink, and every one of them passes through the kitchen.

Words you'll hear

Every technical word this document used, in the order you met it.

browser
The program you are reading this in: Chrome, Safari, Firefox. It opens pages and talks to servers for you.
server
The program that listens for requests and answers them. Yours is server.js, and it runs on your own computer, not on the internet.
page / front end
Everything you can see and click: the form, the list, the search box. The files in public/. Front end is simply the tech name for the part you see.
request / response
One trip: a question your page sends to the server, and the answer that comes back. Every click silently sends one.
API
The kitchen's service window: the fixed menu of messages the server understands. Your kitchen understands three: show me the recipes, save this recipe, search for this word.
JSON
Jason. The plain-text grammar for writing little labeled forms, the one you saw inside a saved recipe. The whole book, and every message between page and kitchen, is written in it.
localhost / port
Your own computer's nickname in the browser. localhost:3000 means this same machine, door number 3000. The port is just a numbered door, and the kitchen listens at door 3000.
validation
The kitchen's quality check before cooking: does this recipe have a name? The polite red error you saw is validation talking.
unique id
A made-up tag, long and random, that no two recipes share, like a raffle ticket stapled to each page of the book.
400 and 404
The kitchen's numbered ways of saying no. 404: never heard of that dish (wrong address). 400: this order doesn't make sense (something was missing or unreadable).

How to explain it to a friend

"Recipe Saver is a digital recipe book that lives on my computer. A page in my browser is the table, a small program called the server is the kitchen, and a single file is the book. When I save a recipe, the kitchen checks it, glues it into the book, and reads the whole book back to my page. When I search, the kitchen flips through every page and serves up only the matches. Nothing goes online. It's all mine."
